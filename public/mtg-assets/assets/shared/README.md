# Shared vectors
All emblems and rarity marks are original interpretations for this interface pack, not official mana, guild, school, or expansion glyphs.
Icons use a 24×24 viewBox and currentColor. Use inline SVG or the sprite to inherit CSS color. An SVG loaded through an img tag cannot inherit its parent's color; use a CSS mask or inline SVG for tinting.
All other SVGs are standalone colored assets. Transparent frames/overlays have no background rectangle. Patterns repeat at their viewBox dimensions. Palette sheets are reference illustrations, not interactive controls.
